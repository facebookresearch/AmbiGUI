# Changelog

All notable changes to this project are listed here.

## 1.0.0 - 2026-10-23

First public release.

- Offline evaluation: inference and metrics on the AmbiGUI gold benchmark.
- Online evaluation: live-browser evaluation with a simulated user, task judge v1 (default) and v2.
- In-context learning baseline (ablation).
- Benchmark: pointer-only annotation files, `benchmark/build.py` to rebuild the benchmark from the
  upstream datasets, and a data card.
